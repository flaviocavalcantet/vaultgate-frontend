The first release of VaultGate's web app: everything a VaultGate user, an outside recipient and an administrator does, in the browser. It covers the plan through **F8** (`docs/architecture.md`, Milestones).

**It pairs with [VaultGate v0.1.0](https://github.com/flaviocavalcantet/vaultgate/releases/tag/v0.1.0)**: the API, the gateway and the scanner it talks to. VaultGate's chart deploys it, and that release's local cluster runs this one, with its browser tests.

## Image

`ghcr.io/flaviocavalcantet/vaultgate-frontend:v0.1.0`: the same image as this release's commit tag, built and scanned by CI. It runs as a non-root, read-only container, and serves HTTPS (TLS 1.3) when given a certificate. Its addresses and Content-Security-Policy come from its environment when it starts (`docs/architecture.md`, The image). With VaultGate's chart, set `frontend.image.tag: v0.1.0`.

## What's in it

- **Sign-in (F1):** OpenID Connect with PKCE through the organization's provider. Tokens are kept in memory only, so a page load starts signed out.
- **Files (F2):**
  - Uploads with progress, straight to the gateway with a single-use intent.
  - Scan states in words, not colour alone: scanning, clean, quarantined (with what was found), unscannable.
  - Downloads handed to the browser's own downloader, at any size, with the token never in an address.
- **Sharing (F3):**
  - One link per recipient, with an expiry and a download limit, and revoking.
  - The recipient's page, with no account: the address proven by an emailed code.
  - Shared with me, for VaultGate users.
- **Administration (F4, F5):**
  - Quarantine, with release and rescan.
  - Access policies, with a dry-run Check access.
  - Users, groups, and the audit log with its chain check.
  - Node enrollment requests (approved by the node's key fingerprint), nodes, enrollment tokens and TPM registrations.
- **Delivery (F6):** the image, deployed by VaultGate's chart. Playwright and axe run against a real VaultGate in VaultGate's CI. An HTTPS development mode is included.
- **Design (F7):** a security-printing look with light and dark colours, Atkinson Hyperlegible, guilloché and status seals, meeting WCAG 2.1 AA.
- **Folders (F8):**
  - Breadcrumbs, new folder, rename, move by browsing.
  - Delete. A folder's deletion shows what goes with it and wants its name typed.
  - Sharing a folder, and browsing one shared with you, signed in or from a link.

## Known limits

- **One language.** Every string goes through i18n, but English is the only translation so far.
- **A failed download shows in the browser's download list, not in the page.** Once the form is handed to the browser, the page doesn't see the gateway's answer.
